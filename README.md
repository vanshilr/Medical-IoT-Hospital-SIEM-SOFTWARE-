# Medical IoT Hospital SIEM

A university cybersecurity project that designs and implements a lightweight Hospital Security Operations Centre (SOC) and SIEM for protecting Medical IoT devices and legacy hospital infrastructure in a controlled, simulated environment.

The system uses a custom Python-based SIEM, hospital asset awareness, real-time monitoring, event correlation, medical-aware dynamic risk scoring, and a Random Forest AI/ML classifier to analyse security events and generate defensive-response recommendations.

The laboratory environment consists of a simulated ICU patient monitor, a Metasploitable2 legacy hospital server, Kali Linux as the authorized security-testing workstation, and a macOS-based Hospital SOC.

Key Features
Real-time hospital security-event monitoring
Medical IoT authentication and telemetry-integrity monitoring
Network reconnaissance detection
Legacy hospital-server monitoring
Hospital asset identification and criticality awareness
AI/ML-assisted threat classification
Medical-aware dynamic risk scoring
Security-event correlation and incident generation
Automated defensive-response recommendations
Persistent alerts, incidents, and response evidence
Technologies

Python • Flask • Scikit-learn • Random Forest • Kali Linux • Nmap • Metasploitable2 • Cisco Packet Tracer • SIEM • MITRE ATT&CK • Zero Trust
